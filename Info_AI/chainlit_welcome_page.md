### ⚙️ Pipeline di Elaborazione Multi-Fase

Ogni tua richiesta viene processata attraverso un processo distribuito a due livelli per garantire il massimo livello di precisione:

```
[Domanda Utente] 
       │
       ├──► 1️⃣  Tavily Web Search (Ricerca Primaria)
       │         └─► Risposta Primaria + Citazione Fonti + Primo Riassunto
       │
       ├──► 2️⃣  Tavily Deep Search (Approfondimento & Normative)
       │         └─► Analisi Integrativa + Secondo Riassunto
       │
       └──► 🎯  Sintesi Finale Unificata & Report Integrato
```
